# WD19 — Графический роман как тип произведения

Подготовлено: 5 ноября 2026 года. **Статус: код подготовлен; production и приёмка ожидаются.**

## Изменения

- БД: `comic_work_type` получает новое значение `GRAPHIC_NOVEL` в миграции `0025_graphic_novel_work_type.sql`. Только `ALTER TYPE ... ADD VALUE`, без изменений данных или структуры `comics`.
- TypeScript: `comicWorkType` и общая таблица названий `workTypeLabels` расширены. Через них новый тип автоматически доступен в редакторе общего и личного произведения, в фильтрах и в отображении карточек, дневника и экспорта.
- Формат (`PAGED`, `WEBTOON` и др.) остаётся независимым от типа: графический роман может иметь любой формат.
- Существующие значения `MANGA`, `MANHWA`, `MANHUA`, `COMIC`, `OTHER`, `UNKNOWN` не меняются; записи типа `OTHER` автоматически **не** преобразуются в графические романы.
- CI: unit-тесты списка значений и PostgreSQL integration probe (сохранение, фильтр, старый импорт, изоляция личных тайтлов).

## Ручная приёмка после зелёного деплоя

1. В админке открыть существующее тестовое произведение без пользовательских отметок, выбрать тип «Графический роман», сохранить, обновить страницу. Проверить выбранный тип.
2. В каталоге открыть фильтры, выбрать «Графический роман»; проверить выдачу и соответствующую подпись на карточке и странице произведения.
3. В «Моём дневнике» убедиться, что тип виден для добавленного произведения; оценки и заметка после перезагрузки не изменились.
4. Проверить отсутствие массовой переклассификации: старые «Другое» остались «Другое».
5. Если доступна функция личных произведений, создать личный графический роман: он должен быть виден только владельцу.

Не подменять реальные названия/обложки и не создавать демонстрационные записи на production автоматически.
