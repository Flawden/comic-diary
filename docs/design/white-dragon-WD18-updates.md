# WD18 — «Обновления» с раскрытием глав на месте

Дата: 5 ноября 2026 года. Статус: патч подготовлен; CI и ручная проверка после деплоя обязательны.

## Цель

Читатель открывает «Обновления», видит, сколько **вышедших непрочитанных** глав у каждой истории, и раскрывает их прямо в списке — без обязательного перехода на страницу произведения. Функция расширяет существующий `ReadingUpdatesList`, а не заменяет бизнес-логику чтения.

## Поведение

- В карточке истории отдельная заметная кнопка «Показать непрочитанные главы · N». Кнопка не конкурирует со ссылкой на сам тайтл; она открывает и закрывает список внутри карточки.
- Если загруженные главы привязаны к томам, внутри появляются группы «Том 1», «Том 2» и «Главы без тома». Первая группа раскрыта сразу. Если номеров томов нет, остаётся обычный список без лишних вложений.
- Глава сохраняет ссылку на первоисточник и кнопку «Отметить прочитанной». Существующая команда «Прочитано до…» остаётся, с явным предупреждением: она отмечает все предшествующие основные главы **через границы томов**.
- Загрузка остаётся ленивой, порциями по 30. Подпись «Показано X из Y» общая; внутри томов количество обозначено «Загружено», чтобы не выдавать частичную выборку за полный размер тома.
- В «Обновления» попадают только главы `RELEASED` из отслеживаемых произведений. `SCHEDULED` и `ARCHIVED` не становятся доступными для оценки/прочтения, а ссылки на запланированные источники не возвращаются.
- Для «Прочитано» можно отменить последнюю одиночную отметку; сетевые ошибки показываются пользователю. Прогресс главы и состояние прочтения остаются на сервере, не привязаны к открытым/закрытым группам.
- На странице комикса полоска прогресса WD17 использует цвета текущей темы и выглядит одинаково в Chromium и Firefox.

## Приёмка

1. В библиотеке есть комикс с 2 вышедшими главами и 1 запланированной; на «Обновлениях» кнопка показывает 2 непрочитанные, запланированная отсутствует.
2. Раскрытие происходит без перехода на страницу произведения. С источником можно перейти наружу по ссылке.
3. Для комикса с томами главы сгруппированы; для комикса без томов список плоский. Не назначаем тома автоматически.
4. Нажать «Прочитано» у одной главы, увидеть уменьшение числа непрочитанных, отменить последнюю отметку.
5. Проверить фильтры «Основные / Спецвыпуски / Обновлённые редакции / Все», пагинацию и загрузку более 30 глав. Число загруженных не выдаётся за общий объём тома.
6. Проверить доступ с телефона, клавиатуры, состояние пустого списка и отсутствие лишних запросов до раскрытия.
7. При любой ошибке UI сообщает об ошибке; сервер продолжает проверять авторизацию, доступ к комиксу и статус главы.

## За пределами релиза

Нет push-уведомлений, автоматической публикации запланированных глав, персональной хронологии релизов, редактирования дат или новых миграций. WD19 остаётся следующим продуктовым этапом.
