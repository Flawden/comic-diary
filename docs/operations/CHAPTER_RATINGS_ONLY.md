# Главы: только оценки

У произведения сохраняются пятикомпонентный отзыв, текст, реакции и модерация.
У главы больше нет списка отзывов, текстового редактора, счётчика отзывов или реакций.
Постраничные обсуждения не реализуются этим изменением; это отдельная задача читалки.
Декоративный росчерк под названием произведения удалён.

## Совместимость данных

Миграции нет. Существующие community_reviews главы остаются в БД и продолжают
давать один голос по прежним правилам RATE. Тексты и spoiler не удаляются:
изменение оценки через новый API сохраняет их побайтно. Они не выдаются новым API.
Снятие оценки использует прежний deleted_at tombstone; возвращение оценки сохраняет
исторический текст, снимает tombstone и очищает прежние реакции по прежнему контракту.
Рейтинг тома и дедупликация одного читателя не изменяются.

Личная оценка дневника остаётся отдельной. У ранее прочитанной главы без нового
публичного голоса кнопка «Моя · дневник» открывает прежний редактор. У публичного
голоса или непрочитанной главы кнопка «Моя оценка» открывает окно только с оценкой.
Снятие публичного голоса не воскрешает автоматически прежнюю дневниковую оценку.

## HTTP

- GET /api/community/chapter-rating?comicId=…&chapterId=… — только собственные
  rating/version/hidden действующей сессии; без текстов, авторов или чужих голосов.
- PUT этого endpoint: comicId, chapterId, rating (1..5 или null), version.
  Текст, spoiler, scores и userId отвергаются строгой схемой.
- Существующий public reviews GET с chapterId возвращает 404, PUT — 400.
  Исторический chapter history GET закрыт. Реакции на chapter review ID возвращают 404.
  Работа с произведением не меняется. Удаление собственного старого отзыва и
  административная модерация сохраняются для управления существующими данными.

Сохранены Origin/Host, bounded JSON, серверная сессия, права, лимиты, CAS, транзакции
и порядок блокировок existing community service. GET не создаёт quota/control row.
Новые ratings используют ту же таблицу и тот же серверный путь записи, без второй
системы рейтингов. Внутренний saveReview остаётся совместимым с историческими
fixtures; публичный текстовый chapter entry point закрыт в HTTP boundary.

Проверки: сохранность текста/дневника, отсутствие чужих DTO, replay/concurrency,
CAS, expiry, malformed/foreign/scheduled targets, rate limit после снятия голоса,
work review regression, браузерный score-only flow, три темы и отсутствие росчерка.
AUTH, environment, gates и пилот этим изменением не затрагиваются.
